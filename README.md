# Proba Tehnic LigaAC 

Aplicatie web construită cu Next.js pentru gestionarea conținutului (utilizatori, idei, postări, contact). 

Scop: demo / proiect de test.

Link production: https://proba-ligaac.mbd.one

Date test:
- Email: `test@mbd.one`
- Parolă: `demo`

Ce face proiectul
- Interfață front-end Next.js (React) cu pagini și componente în [pages/](pages/) și [components/](components/).
- API routes simple în [pages/api/](pages/api/).
- Autentificare/gestionare sesiune în [lib/auth.js](lib/auth.js).
- Conectare la MongoDB în [lib/mongodb.js](lib/mongodb.js).

Instalare (local)
1. Descarcă repo.
2. Instalează dependențele:
```sh
npm install
```
3. Rulează în mod dezvoltare:
```sh
npm run dev
```

Aplicația va porni pe http://localhost:3000 sau pe primul port liber.
